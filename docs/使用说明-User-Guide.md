# FCPX2PR 1.0 使用说明 / User Guide

作者 / Author: **ameng**

## 简体中文

### 一、系统要求

- macOS 12 或更高版本
- Apple 芯片或 Intel 芯片 Mac
- 可导出 FCPXML 的 Final Cut Pro
- 可导入 XML 的 Adobe Premiere Pro

### 二、安装

1. 下载并双击打开 `FCPX2PR-1.0.dmg`。
2. 把 FCPX2PR 拖到 Applications（应用程序）文件夹。
3. 第一次打开时，如果 macOS 提示无法验证开发者，请在“应用程序”文件夹中右键点击 FCPX2PR，选择“打开”，然后再次确认。

### 三、从 Final Cut Pro 导出

1. 在 Final Cut Pro 中选中需要转换的项目或时间线。
2. 使用 Final Cut Pro 的 XML 导出功能，保存为 `.fcpxml`；如果导出结果是 `.fcpxmld` 时间线包，也可以直接使用。
3. 不要移动或重命名原素材、素材文件夹和外接硬盘。

### 四、转换为 Premiere XML

1. 打开 FCPX2PR。
2. 把 `.fcpxmld` 或 `.fcpxml` 拖入窗口，也可以点击“选择 FCPXML 文件…”。
3. 检查项目列表和素材检查状态。如果提示素材缺失，请先重新连接硬盘或恢复原素材路径。
4. 点击“选择位置…”设置保存目录；如果不提前设置，点击转换时软件会询问保存位置。
5. 点击“转换为 Premiere XML”，等待进度条到达 100%。
6. 转换完成后，点击“在访达中显示”定位生成的 XML。

### 五、导入 Adobe Premiere Pro

1. 打开 Adobe Premiere Pro。
2. 选择“文件 > 导入”。
3. 选择 FCPX2PR 生成的 Premiere XML。
4. 导入后检查画面、剪辑点和音频轨道。

### 六、注意事项

- 在 Premiere 完成导入前，请保持原素材硬盘连接。
- 硬盘卷名、文件夹结构或素材文件名发生改变时，Premiere 可能提示素材离线，需要手动重新链接。
- Final Cut Pro 专属的调色、LUT、语音隔离、部分转场、标题和第三方插件效果，不一定能写入 Premiere XML，需要在 Premiere 中重新制作。
- “关于”窗口包含免费声明、版本和作者信息；“赞助”仅显示作者的微信赞赏码，赞助完全自愿，不影响任何功能。

## English

### 1. System requirements

- macOS 12 or later
- Apple silicon or Intel Mac
- Final Cut Pro with FCPXML export support
- Adobe Premiere Pro with XML import support

### 2. Installation

1. Download and open `FCPX2PR-1.0.dmg`.
2. Drag FCPX2PR into the Applications folder.
3. If macOS cannot verify the developer on first launch, right-click FCPX2PR in Applications, choose **Open**, then confirm.

### 3. Export from Final Cut Pro

1. Select the project or timeline you want to convert.
2. Use Final Cut Pro's XML export command and save a `.fcpxml` file. A `.fcpxmld` timeline package can also be used directly.
3. Do not move or rename the source media, media folders, or external drive.

### 4. Convert to Premiere XML

1. Open FCPX2PR.
2. Drop a `.fcpxmld` package or `.fcpxml` file into the window, or click **Choose FCPXML Files…**.
3. Review the project list and media-check status. If media is reported missing, reconnect the drive or restore the original media path first.
4. Click **Choose…** to select an output folder. If you do not choose one in advance, FCPX2PR asks when conversion starts.
5. Click **Convert to Premiere XML** and wait for the progress bar to reach 100%.
6. When conversion finishes, click **Show in Finder** to locate the generated XML.

### 5. Import into Adobe Premiere Pro

1. Open Adobe Premiere Pro.
2. Choose **File > Import**.
3. Select the Premiere XML generated by FCPX2PR.
4. After import, check the picture, edit points, and audio tracks.

### 6. Notes

- Keep the source media drive connected until the Premiere import is complete.
- If the drive name, folder structure, or media filenames change, Premiere may report offline media and require manual relinking.
- Color grades, LUTs, Voice Isolation, some transitions, titles, and third-party effects unique to Final Cut Pro may not transfer through Premiere XML and may need to be recreated.
- **About** contains the free-use statement, version, and author information. **Sponsor** only displays the author's WeChat sponsor code; sponsorship is optional and never changes available features.
